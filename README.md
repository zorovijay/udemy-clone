# Udemy Clone Website

A **Udemy Clone Website** developed using HTML and CSS to replicate the design and layout of the Udemy online learning platform. The project demonstrates front-end web development skills, including webpage structuring, styling, layout design, and user interface development.

## Technologies Used
- **HTML5** – For structuring webpage content.
- **CSS3** – For styling, layout, and visual presentation.

## Features
- Clean and user-friendly interface
- Course listing and category sections
- Navigation bar and search interface
- Responsive layout and structured content
- Design inspired by the Udemy learning platform

## Purpose
This project was created to strengthen my front-end development skills and gain practical experience in building educational website interfaces using HTML and CSS.
